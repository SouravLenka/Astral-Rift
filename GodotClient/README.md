# Astral Rift — Godot Edition

The new code-first Godot 4 .NET implementation. The Unity project remains in this repository as reference.

## Run

1. Install the **Godot 4 .NET** editor and the .NET 8 SDK.
2. Import `GodotClient/project.godot` in Godot.
3. Press **F6** or **F5**.

| Player | Move | Fire |
| --- | --- | --- |
| Pilot One | `W A S D` | `Space` |
| Pilot Two | Arrow keys | Numpad `0` |

The starter arena includes co-op movement, shooting, enemy pursuit, escalating waves, and timed pickups:

- Purple: Triple Shot
- Yellow: Rapid Fire
- Green: Speed Boost
- Red: Double Damage
